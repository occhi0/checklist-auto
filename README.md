# Checklist Auto – Rimpatrio Golf

Checklist in un unico file HTML per seguire i passaggi di rimpatrio dell'auto (Svizzera → Italia):
assicurazione, motorizzazioni, dogana, Camorino, apostille, immatricolazione a Foggia.

- Spunte con data, note per ogni voce, voci aggiunte a mano
- Giorni mancanti alla scadenza di ogni gruppo e "prossimo passo"
- Dati salvati solo sul dispositivo (localStorage); Esporta/Importa per spostarli
- Installabile come app dal browser (icona e manifest inclusi)

Pubblicata con GitHub Pages: https://occhi0.github.io/checklist-auto/
